# Tienda Desktop (MVP)
Sistema desktop offline para gestión de tiendas (Windows), desarrollado en Java + JavaFX + SQLite.

## MVP
- Login dueño
- Productos (unidad / kg) + categorías
- Stock (entrada/salida/ajuste) sin negativos
- Caja (ventas) + ticket
- Informe diario (ventas + movimientos + ganancia)
